# ADR-0003. Полнотекстовый поиск через OpenSearch, а не через SQL LIKE

**Дата:** 2026-09-04
**Статус:** принято

## Контекст

ВИ-01 «Найти книгу» требует поиска по автору, названию и ISBN с откликом
меньше 1 секунды при миллионе записей. Основная БД — PostgreSQL.

## Рассмотренные варианты

1. Поиск через `SELECT ... WHERE название LIKE '%...%'` в PostgreSQL.
2. Отдельный поисковый индекс OpenSearch, синхронизируемый с БД.

## Решение

Вариант 2.

## Последствия

**Плюсы:** отклик меньше 1 с при миллионе записей; морфология,
опечатки, ранжирование; не нагружает основную БД.

**Минусы:** отдельный контейнер для эксплуатации; нужна синхронизация
индекса с БД (через доменные события); eventual consistency — книга,
только что добавленная в БД, может появиться в поиске с задержкой.

**Что станет неверным, если решение пересмотреть:** диаграммы C4
Container и Component, требования к отклику в `traceability.md`.
